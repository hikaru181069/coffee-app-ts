# 知識グラフ

## 点と線

- 点: 記録と属性（産地・品種・精製方法・焙煎度・フレーバー）
- 線: 記録と、その記録の属性をつなぐ
- 点には「種類と番号」の両方を持たせる（例: `origin-3`）。選択肢の番号は種類ごとに付けるので、番号だけだと産地の3番とフレーバーの3番を見分けられないため

## 見た目

- 属性の点の大きさ: その属性の記録の数（よく飲んでいるほど大きい）
- 点の色: 属性の種類ごとに分ける

## 押したとき

- 点を押すと、その点にフォーカスする（つながっている点と線だけをはっきり見せ、ほかはうすくする）
- フォーカスすると、点の名前と「詳細を見る」ボタンを出す
  - 記録の点: 記録の詳細画面へ
  - 属性の点: 記録の一覧画面に移り、その属性の記録だけを出す
- 何もないところを押すと、フォーカスを外す

## なぜこうしたか

- 自分の記録がどこにつながっているかを確かめられるように、記録と属性の両方を点にした
- 自分の好みが一目で分かるように、よく飲んでいる属性ほど点を大きくした
- グラフはどんなコーヒーを飲んだかを知るためのものなので、評価は使わない
- 評価を使わないので、色は属性の種類で分けて、どの点が産地でどれがフレーバーかを一目で分かるようにした
- 押した点にフォーカスして、どこにつながっているかを図の中で確かめられるようにした
- フォーカスしたあとは「詳細を見る」ボタンで画面を移る。スマホで使うことが多いので、押すと何が起きるか見て分かるようにした
