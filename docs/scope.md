# 機能の範囲

## まず作る機能

1. ログイン — 登録・ログイン・ログアウト
2. 記録 — コーヒーの記録を作る・見る・直す・消す
3. 知識グラフ — 記録どうしのつながりを図で見せる
4. 選択肢の一覧 — 産地・品種・焙煎度などを選ぶリスト（書き方のばらつきを防ぐ）

あわせて作るもの:

- ホーム — 最近の記録・「新しく記録」ボタン・知識グラフへの入り口
- お試しで使う — 押した人ごとにお試し用アカウントを作り、登録なしで全部の機能を試せる（24時間で自動で消える）
- タグでしぼりこみ — 記録に付いた産地・フレーバーなどのタグを押すと、同じタグの記録だけ一覧に出す
- プロフィール — 名前の変更・パスワードの変更・ログアウト・退会

## 今は作らない機能（あとで考える）

パスワードを忘れたときの再設定、傾向の一言、検索、項目の詳細ページ、統計、おすすめ、コーヒー診断、世界地図、似ている記録、抽出の詳細

※ 抽出の詳細のうち、粉の量・お湯の量・抽出時間だけは記録に入れた（`data.md` を参照）

## なぜこうしたか

- まずは最小限で動くものを作ってから、あとで機能を足せばいいと考えた。
- ただし、退会とパスワードの変更ができないのはアプリとして致命的なので、プロフィールは作る。パスワードを忘れたときの再設定は、メールを送る仕組みが必要で大きくなるので、あとにした
