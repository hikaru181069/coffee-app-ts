# 機能の範囲

## まず作る機能

- ログイン — 登録、ログイン、ログアウト
- 記録 — コーヒーの記録を作る、見る、直す、消す
- 知識グラフ — 記録と産地、フレーバーなどのつながりを図で見せる
- 選択肢の一覧 — 産地、品種、精製方法、焙煎度、フレーバーを選ぶリスト
- ホーム画面 — 最近の記録、「新しく記録」ボタン、知識グラフへの入り口
- タグで絞り込み — 記録に付いた産地、フレーバーなどを押すと、同じものを持つ記録だけを出す
- プロフィール — 名前の変更、パスワードの変更、退会
- デモアカウント — 登録しなくても、ボタン1つで全部の機能を試せる(24時間で消える)

## 今は作らない機能(あとで考える)

- 好きな傾向
- 検索機能
- 項目の詳細ページ
- 統計情報
- おすすめ
- 世界地図
- 診断
- 似ている記録
- 抽出の詳細(ただし、粉の量、お湯の量、抽出時間だけは記録に入れた。`data.md` を参照)
- パスワードを忘れた時の再設定

## なぜこうしたか

- まずは最小限で動くもの(コーヒーアプリとしての最低限)を作ってから、あとで機能を足せばいいと考えた。
- 知識グラフはこのアプリの個性となるところなので、初めの段階から導入した。
- デモアカウントは、このアプリを気軽に試せるようにしたかったから導入した。
- パスワードを忘れたときの再設定は、メールを送る仕組みが必要で大きくなるので、あとにした。
