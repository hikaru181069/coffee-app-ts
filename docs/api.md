# API

## ログイン

- `POST /api/auth/register` ユーザー登録
- `POST /api/auth/login` ログイン
- `POST /api/auth/logout` ログアウト
- `GET /api/auth/me` 今ログインしているのはだれかを確かめる
- `PATCH /api/auth/me` 名前を変える
- `PATCH /api/auth/password` パスワードを変える（今のパスワードと新しいパスワードを送る）
- `DELETE /api/auth/me` 退会（パスワードを送る）
- `POST /api/auth/demo` お試し用アカウントを作って、ログインする

### お試しで使う

- 押すたびに、その人専用のお試し用アカウントを作り、サンプル記録を写して入れる
- メールアドレスとパスワードは自動で作り、本人には見せない
- 作ってから24時間たったお試し用アカウントは、だれかが「お試しで使う」を押したついでに消す
- パスワードを知らないので、お試し用アカウントではパスワードの変更と退会はできない（24時間で自動で消える）

### ログインの方法

- セッションを使う。ログインすると、サーバーが受付番号を作ってデータベースに保存し、ブラウザのクッキーに入れる
- クッキーは、画面のプログラムから読めない設定にする
- ログアウトすると、その受付番号を消す
- パスワードを変えたとき・退会したときは、その人の受付番号を全部消す

## 記録

- `GET /api/records` 自分の記録の一覧（飲んだ日が新しい順。同じ日なら作った日時が新しい順）
  - `?limit=5` 新しい順に5件だけもらう（ホームの「最近の記録」で使う）
  - タグでしぼりこむ（そのタグを持つ記録だけを出す）。種類ごとに名前を分ける
    - `?origin=〇` 産地
    - `?variety=〇` 品種
    - `?process=〇` 精製方法
    - `?roast=〇` 焙煎度
    - `?flavor=〇` フレーバー
- `POST /api/records` 記録を作る
- `GET /api/records/:id` 記録を1件見る（`:id` は記録の番号）
- `PATCH /api/records/:id` 記録を直す
- `DELETE /api/records/:id` 記録を消す

## 選択肢の一覧

- `GET /api/options` 産地・品種・精製方法・焙煎度・フレーバーの一覧をまとめてもらう

## 知識グラフ

- `GET /api/graph` 自分の記録から作ったグラフ（点と線）をもらう

## なぜこうしたか

- よく使われる決まった書き方（REST）にした。ほかの人が読んでもすぐ分かるため
- 全部の先頭に `/api` を付けた。VPS の入口（Caddy）で、`/api/〜` はサーバー（Hono）へ、それ以外は画面（React）へと、先頭だけで振り分けられるため。画面の URL（例: `/records`）とぶつからないようにするためでもある
- ログインはセッションにした。前のアプリは JWT だったが、JWT はログアウトしても期限まで使えてしまう。ログアウト・退会・パスワード変更のあと、その場で確実にログインを切れるようにするため。画面とサーバーを同じ VPS に置くので、クッキーがそのまま使えるためでもある
- お試しは、押した人ごとに別のアカウントを作るようにした。全員で1つを使うと、だれかが消したり足したりした記録が次の人にも見えてしまうため。見るだけにすると、中心の「記録する」を試せないため
- 古いお試し用アカウントは、「お試しで使う」が押されたついでに消す。時間ごとに動かす仕組みを別に作らなくてよいため
- ログインまわりは `/api/auth` にまとめた。auth は「認証（この人はだれかを確かめること）」の意味で、よく使われる名前のため
- 選択肢は、記録を作る画面で全部使うので、1回でまとめてもらえるようにした
- 最近の記録とタグでのしぼりこみは、新しい API を作らず、記録の一覧 API に条件を付ける形にした。どちらも「記録の一覧」の一部なので
- 記録の並び順は、飲んだ日の順にした。どんなコーヒーを飲んだかを見るアプリなので、飲んだ順に並ぶほうが自然なため。同じ日の記録は作った日時の順にして、順番が毎回変わらないようにした
- タグでのしぼりこみは、種類ごとに名前を分けた（`?origin=3` など）。選択肢の番号は種類ごとに付けるので、番号だけだと産地なのかフレーバーなのか分からないため。見ただけで何でしぼりこんでいるか分かり、あとで組み合わせることもできる
